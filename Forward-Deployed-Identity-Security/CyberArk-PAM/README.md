# CyberArk PAM

*Starting. Labs will be added here as I complete them.*

Privileged Access Management with CyberArk: keeping admin credentials out of people's hands and making every privileged session traceable.

## Planned labs

- [ ] **Vault administration:** how the Digital Vault stores and protects credentials
- [ ] **Safes:** organizing credentials and setting who can use, see or manage them
- [ ] **Platforms:** password rules and rotation policies for different account types
- [ ] **Component architecture:** how the Vault, PVWA, CPM and PSM fit together

## The GRC angle

For each lab I'll note which control it supports, so the technical work maps back to compliance:

| Lab | Control |
|---|---|
| Safes and permissions | AC-6 Least Privilege |
| Password rotation | IA-5 Authenticator Management |
| Session recording | AU-2 Event Logging |
