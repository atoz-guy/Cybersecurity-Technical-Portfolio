# Practical Security Analyst (PSAA) Labs

Hands-on labs from TCM Security's PSAA course. Each one goes past the technical piece and ties it back to GRC: a risk score, the NIST controls that failed, and how it gets tracked to closure in ServiceNow.

| Lab | Topic | Key controls |
|---|---|---|
| [Lab 001](Lab-001-Access-Control-Review.md) | Internal access control review | PS-4, AC-2, AC-7 |
| [Lab 002](Lab-002-Phishing-Investigation.md) | Phishing & BEC investigation | IA-2(1), SI-8, AT-2 |
