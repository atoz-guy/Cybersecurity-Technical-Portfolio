# Analysis: After It Happens

These come from TCM Security's Practical SOC Analyst Associate (PSAA) course, the same track as my [SOC-Defensive-Labs](../../SOC-Defensive-Labs). Each lab here goes past the technical piece and ties it back to GRC: a risk score, the NIST 800-53 controls that failed, and how it gets tracked to closure in ServiceNow.

Risk scores use Likelihood x Impact. See the [risk matrix](risk-matrix.md).
